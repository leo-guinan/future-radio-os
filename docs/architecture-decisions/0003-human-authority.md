# ADR 0003: Keep authority outside model output

Status: accepted for the first implementation

## Decision

Permission-checked APIs and explicit session policy determine what an agent may do. Model output, web text, audience comments, and adapter responses cannot widen authority.

## Consequences

Publishing, spending, external outreach, credential use, and canon changes require explicit gates. The first execution contract must include budgets, allowed tools/environments, data scope, approvals, and stop conditions.
